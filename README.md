# Java Programming Practice

This repository contains my Java programming practice programs. These programs help me improve my problem-solving skills and understand basic programming concepts.

## Programs

### 1. FizzBuzz (`fizzbuzz.java`)
- Prints numbers from 1 to 100.
- Prints **Fizz** when a number is divisible by 3.
- Prints **Buzz** when a number is divisible by 5.
- Prints **FizzBuzz** when a number is divisible by both 3 and 5.

### 2. Number of 1 Bits (`bits.java`)
- Counts the number of set bits (1s) in the binary representation of an integer.
- Uses bitwise AND (`&`) and unsigned right shift (`>>>`).

**Example:**
```text
Input: 11
Binary: 1011
Output: 3
```

### 3. Add Digits (`addDigits.java`)
- Repeatedly adds the digits of a number until a single digit remains.
- Uses loops, modulus (`%`), and division (`/`).

**Example:**
```text
Input: 38
Output: 2
Explanation: 3 + 8 = 11, 1 + 1 = 2
```
